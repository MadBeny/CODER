For macOS

Because your app isn't "signed" by an Apple Developer account (which costs $99/year), macOS will likely block it with a popup saying:

"moon_mac_intel cannot be opened because the developer cannot be verified."

How to bypass this:

click Cancel on that popup.
Go to the Mac System Settings (or System Preferences).
Go to Privacy & Security.
Scroll down until they see a message saying "moon_mac_intel" was blocked...
Click Open Anyway.
They will have to type their Mac password, and then the app will launch.
Summary for your users (Copy-paste this):

OR:
 
chmod +x moon_mac_intel

./moon_mac_intel (And tell them to click "Open Anyway" in System Settings if macOS blocks it).


For Linux

Open the Terminal.
Navigate to the folder:

cd ~/whatever

Make it executable (The chmod step):

chmod +x moon_linux_amd64

Run it:

./moon_linux_amd64

The Graphical Way (GUI)

Open the File Manager and find the file.
Right-click the file and select Properties.
Go to the Permissions tab.
Check the box that says "Allow executing file as program" (or something similar like "Is executable").
Close the window.
