if you don’t like PowerShell and want a better looking MoonApp
instead of double clicking on MoonApp.exe 
do this:


1. Open VS Code
2. Change Theme to "Light 2026"
3. File -> Open Folder
4. Open the folder that contains MoonApp.exe
5. ... -> Terminal -> New Terminal
6. Run this code: ./MoonApp.exe (or ./MoonApp)
