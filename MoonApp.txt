Important: This is the Chatbot version of Moon, If you want full capabilities, Use NewMoonCoder.

Step 1: Prerequisites (Required)

Before running the app, you must have the "brain" (Ollama) installed and running.

  Install Ollama: Download and install it from ollama.com

  Keep Ollama Running: Ensure the Ollama icon is visible in your system tray (Windows)


Step 2: Set Terminal to "Light Mode" (Crucial)

-> If you skip this, the app will be unreadable <-


For Windows Users (Windows Terminal / PowerShell)

  Open Windows Terminal (the modern version of PowerShell).

  Click the down arrow in the tab bar and select Settings.

  On the left sidebar, click on Color Schemes.

  Select a light theme such as "One Half Light" or "Tango Light".

  Click Save.

  Restart PowerShell


For macOS Users (Default Terminal.app)

 Open Terminal (found in Applications > Utilities).

 In the top menu bar, click Terminal and select Settings... (or Preferences on older macOS versions).
 
 Click on the Profiles tab at the top.

 On the left sidebar, select a light theme such as "Basic" or "Silver".

 Click the Default button at the bottom of the sidebar to ensure it stays this way.

 Close the window and open a new Terminal window.


For Linux Users (GNOME Terminal / Ubuntu / Fedora)

 Open your Terminal.

 Click the Menu icon (three horizontal lines) in the top right corner and select Preferences.

 On the left sidebar, click on your active profile (usually named "Unnamed" or "Default").

 Click on the Colors tab.

 Uncheck the box that says "Use colors from system theme."

 Under "Built-in schemes," select a light scheme such as "Solarized light" or simply change the text/background colors to a light preset.

 Close the window and restart your Terminal.
